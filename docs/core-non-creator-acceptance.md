# Core non-creator acceptance

Status: C10 accepted for the synthetic Goal 1 vertical slice. This is the
final non-creator Core operator-panel gate; it is not the contact-sheet or
carousel implementation, which remains the C11 follow-on.

## Qualified path

`qualifyCoreGoal1NonCreator` composes the real C01-C04 and C09 application
services against a disposable in-memory self-hosted fixture. The rehearsal
records a timezone and room/screen in a draft, records an application-managed
manual source with an existing screen mapping, validates that draft, creates a
non-mutating preview, activates the candidate revision, projects its injected
normalized frames, rotates a class code, creates a redacted portable export,
accepts exact-workspace recovery preflight, and rolls the active revision back.

The evidence deliberately reports only finite outcomes. It never returns the
one-time class code, a viewer session, source content, protected reference, or
provider value. A loopback HTTP integration check separately confirms that the
private operator listener renders the planned-display summary while an apparent
`/screens/:id` route is unknown and forwarded metadata is rejected.

## What this accepts

The gate establishes that a competent self-hosting operator can use the
implemented configuration lifecycle and private operator shell together,
without an account, login, commercial framework, provider enrollment, or live
effect. It confirms continuity through redacted export, recovery preflight, and
rollback rather than claiming a durable production configuration adapter.

## Limits retained after C10

This remains synthetic and in-memory. C04 records draft-only, teacher-entered
application-managed metadata and mappings; it does not parse, upload, fetch,
or acquire any source. C09 projects only injected normalized frames and does
not infer content or mutate a provider, Calendar, or configuration. The Core
operator listener has no public display/viewer route. C10 adds no contact
sheet, thumbnail, modal, carousel, date-picker, OAuth, provider client,
account, durable store, deployment, or live-service change.
