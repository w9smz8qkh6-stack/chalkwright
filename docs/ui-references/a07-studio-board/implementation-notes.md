# Implementation notes

Status: retained exploratory concept; not selected as the global IA.

## Decision

The central stage, right review inspector, bottom contact sheet, and persistent
preview-only signal are strong planned-display patterns. The concept is not the
global direction because a compact top bar makes the full Core MVP less
discoverable and would force setup, sources, configuration history, and
recovery into shallow or hidden navigation.

The selected readiness-rail reference therefore owns the global IA. A
code-native planned-display region may borrow the studio's page-level stage and
contact-sheet composition while retaining the selected rail, semantic DOM
order, predictable focus return, and responsive stacked layout.

Generated display artwork, dates, names, icons, typography, and small copy are
not implementation inputs.
