# A07 code-native operator reference brief

## Outcome

Translate the selected readiness-rail direction into a nonproduction native
TypeScript/server-rendered HTML/CSS reference gallery for the seven Core
operator areas. The reference must demonstrate the shell-neutral Core feature
region inside both self-hosted and hosted wrappers without defining routes,
persistence, authentication, provider flows, or live application behavior.

## Required evidence

- Synthetic, privacy-safe fixture content only.
- Overview, displays, sources, planned display, presentation, configuration,
  and diagnostics/recovery models.
- Finite loading, empty, validation, conflict, success, partial, degraded,
  stale, disabled, unavailable, destructive, and recovery treatments in
  addition to ready.
- Browser checks at 390x844, 768x1024, 1366x768, and 1920x1080, plus the
  effective CSS viewport exposed by 200% zoom from 1366x768.
- Visible keyboard focus, reduced-motion behavior, no horizontal overflow,
  no console/page errors, and contact-sheet keyboard/focus-return behavior.

## Non-goals

No production route, navigation binding, form submission, mutation, provider
authentication, account UI, organization selector, or authorization decision.
