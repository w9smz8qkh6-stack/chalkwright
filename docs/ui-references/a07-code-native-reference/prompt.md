# A07 code-native translation specification

Implement the selected A07 readiness-rail concept as a native TypeScript
server-rendered HTML/CSS reference gallery. Preserve Chalkwright's dark
presentation vocabulary while making readiness, setup progression,
last-known-good continuity, draft/effective configuration, and safe next
actions immediately legible. Use a persistent shell-owned operator-area rail,
a shell-owned fixed-scope context band, and a route-independent Core feature
region. Borrow the rejected studio-board concept only for the planned-display
stage and keyboard-operable contact sheet. Keep all copy synthetic.

The Core fragment must contain no document wrapper, route, URL, form target,
cookie, session, account, membership, role, billing, authorization, provider
payload, or raw HTML field. Demonstrate identical Core fixture rendering inside
synthetic self-hosted and hosted wrappers. Use semantic landmarks, headings,
buttons, live status, visible focus, non-color-only states, responsive reflow,
and reduced-motion support. This is a nonproduction visual and contract
reference, not a live operator panel.
